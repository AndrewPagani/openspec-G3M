# Orientações para esta change

Por solicitação do usuário, usar a skill `impeccable` para o planejamento,
implementação e revisão da interface da tela de venda desta change.
Ler o `SKILL.md` da skill instalada antes de aplicá-la e escolher o fluxo
adequado à tarefa de UX/design em andamento.

Ao trabalhar no app com base nesta change, levar essa orientação para os
arquivos de interface afetados. Manter as decisões de `exploration.md`,
a seleção visual de veículos/peças e os contratos Xano/ASAAS verificados.
A skill orienta a interface; regras de negócio e backend seguem as specs.
