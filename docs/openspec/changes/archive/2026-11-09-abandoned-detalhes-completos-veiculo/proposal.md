# Detalhes completos do veículo

Criar uma tela autenticada de detalhes do veículo, com hierarquia visual
consistente com o tema escuro do AutoGestão. Os dados adicionais ficam em uma
tabela própria, vinculada por `veiculo_id`, preservando o cadastro base de
veículos e permitindo evolução independente.

O escopo inclui identificação documental, especificações técnicas e
opcionais/equipamentos em formato de tags.
